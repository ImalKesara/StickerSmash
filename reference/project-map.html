StickerSmash project map

A quick way to decide where a change belongs.

src/app/
Expo Router route files only. Each screen file becomes a route.
src/app/index.tsx
The root route (/), currently the starter screen.
src/app/_layout.tsx
Root navigator shared by routes; currently renders a Stack.
src/components/
A useful future home for reusable UI, outside the route directory.
assets/images/
Images referenced by screens or app configuration.
app.json
Expo app identity and platform/build configuration; icon, splash, plugins, orientation.
package.json
Project entry point, dependencies, and npm scripts.
package-lock.json
Exact dependency resolution for reproducible npm installs.
tsconfig.json
TypeScript settings and import aliases such as @/* → src/*.
expo-env.d.ts
Expo/Router TypeScript environment declarations; generally generated.
.expo/
Local generated Expo state and route types; usually not hand-edited.
example/
Archived starter example code/scripts; not active routes because it is outside src/app/.
.gitignore
Files Git should leave untracked, often generated or machine-local files.
.vscode/
Editor recommendations and workspace preferences.
AGENTS.md
Repository instructions for humans and coding agents.
README.md
Project introduction and basic start instructions.
skills-lock.json
Tooling/skill setup metadata, not app runtime code.
LICENSE
Terms for using and distributing the project.

No ios/ or android/ folders are present. This project uses Expo's generated-native-project workflow; configure native behavior through Expo config and plugins.

Layout and tabs in this project

src/app/_layout.tsx creates the root Stack and registers the (tabs) group as one child screen. src/app/(tabs)/_layout.tsx creates the tab bar; its direct child routes index.tsx and about.tsx are the Home and About tabs. The parentheses mark a route group and are not part of the URL.
