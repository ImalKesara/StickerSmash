Layouts and tabs

src/app/_layout.tsx          root Stack
└── (tabs)/                  route group, no URL segment
    ├── _layout.tsx          Tabs navigator / tab-bar setup
    ├── index.tsx            Home tab, URL /
    └── about.tsx            About tab, URL /about
Root _layout.tsx
Owns app-wide navigator/providers and how top-level routes are arranged.
<Stack.Screen name="(tabs)">
Configures the group in the parent Stack (for example, hide its header). It does not create the tabs.
(tabs)
Route group folder: groups related screens without adding “tabs” to their URL.
Tabs _layout.tsx
Returns <Tabs> and configures tab titles, icons, colors, and headers.
<Tabs.Screen name="index">
Configures the existing index.tsx child route as a tab. The file supplies the screen content.
Current tab
Only the selected tab’s page content is shown in the content area; the tab bar lets the user switch between tabs.
