Props and image sources

Prop
A named value the parent gives a component in JSX, e.g. imageSource={placeholderImage}.
Props object
React calls the component with one object: { imageSource: placeholderImage }.
Destructuring
function ImageViewer({ imageSource }) pulls the imageSource property into a local variable. Equivalent: function ImageViewer(props) { const imageSource = props.imageSource; }.
Type annotation
type Props = { imageSource: ImageSourcePropType } describes the shape of that object and the allowed value type for its field.
ImageSourcePropType
React Native's type for image sources, including a local require(...) result and source objects such as { uri: 'https://…' }.

The braces mean different things in different places: in the function parameter they destructure an object; in JSX, braces switch from text/attribute syntax to a JavaScript expression.
