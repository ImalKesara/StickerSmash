# Mission: Expo fundamentals

## Why
Learn the foundations of Expo by understanding and gradually building this StickerSmash app. The goal is to confidently find where app behavior belongs and make small changes that run across mobile and web.

## Success looks like
- Explain how this project's folders and key files work together.
- Know where to add a screen, shared component, image, or Expo setting.
- Make and run small changes in the app with confidence.

## Constraints
- Teach in short, practical lessons grounded in this repository.
- Follow the Expo SDK version used by this project.

## Out of scope
- Native iOS or Android project internals until the app needs them.
