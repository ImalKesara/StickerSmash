Root layout, tabs layout, and what appears

The root layout and the tabs layout are two different navigators, nested one inside the other.

Think of a container inside a container

src/app/_layout.tsx
  Stack navigator
    └── (tabs) group      ← one screen/group inside the Stack
         Tabs navigator   ← creates the tab bar
           ├── index.tsx  ← Home tab
           └── about.tsx  ← About tab

A layout is a parent wrapper for the routes in its folder. The root _layout.tsx currently returns a Stack and configures <Stack.Screen name="(tabs)" ... />. That names the child group so you can set options such as hiding the Stack header. The name does not mean “show every tab at once,” and it does not create the tab pages.

What actually makes the tabs?

Inside src/app/(tabs)/_layout.tsx, your app returns <Tabs>. Its <Tabs.Screen name="index"> and <Tabs.Screen name="about"> configure the matching page files, including icons. The page files supply the content. The tab bar stays available while the selected page is shown; selecting About switches the content from index.tsx to about.tsx. It does not put both pages on screen together.

Why the parentheses?

(tabs) is a route group name used to organize and share a layout. Parentheses keep the group name out of the URL. So your Home page is / and About is /about, not /(tabs)/about.

Make the file tree do the talking

To check what your tab bar can show, look inside src/app/(tabs)/. In this project, the two page files are index.tsx and about.tsx; those correspond to the Home and About tabs configured in that folder's layout. Adding another direct route file and configuring it as a Tabs.Screen gives the tab navigator another route to show.

Remember: the root Stack hosts the tabs group; the Tabs navigator controls switching among its child pages. The group name is organizational; the page files are routes.

Quick recall

If you want to change an About icon, which layout file should you edit? If you want to change the words on the About page, which file? Answer before opening the reference.
