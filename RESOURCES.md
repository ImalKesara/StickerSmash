# Expo Fundamentals Resources

## Knowledge

- [Expo SDK 57 documentation](https://docs.expo.dev/versions/v57.0.0/)
  Version-matched reference for the Expo SDK and supported packages; use when checking APIs and platform support.
- [Expo Router introduction](https://docs.expo.dev/router/introduction/)
  Official overview of file-based navigation, shared platforms, and routes; use when adding or navigating between screens.
- [Expo Router core concepts](https://docs.expo.dev/router/basics/core-concepts/)
  Explains route files, `index.tsx`, `_layout.tsx`, and which code belongs outside `src/app/`.
- [Expo Router navigation layouts](https://docs.expo.dev/router/basics/navigation-layouts/)
  Shows how root, stack, and tab layouts nest, and how files inside a tab directory map to tabs.
- [Expo app config reference](https://docs.expo.dev/versions/v57.0.0/config/app/)
  Documents `app.json` properties such as app name, icons, orientation, and plugins.
- [Expo tutorial](https://docs.expo.dev/tutorial/introduction/)
  Guided project-based path for building an Expo app that runs on mobile and web.
- [Expo Image (SDK 57)](https://docs.expo.dev/versions/v57.0.0/sdk/image/)
  Version-matched API reference for `expo-image`, including its `source` prop and supported source forms.
- [Passing props to a component](https://react.dev/learn/passing-props-to-a-component)
  React's primary guide to passing values into components and reading them from the props object.

## Wisdom (Communities)

- [Expo Discord](https://chat.expo.dev/)
  Community for practical questions about Expo and React Native; use when project-specific experimentation leaves a question open.
